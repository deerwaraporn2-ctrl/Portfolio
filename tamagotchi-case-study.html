Tamagotchi Game

Frontend Developer Project (2026)

A browser-based virtual pet simulation built with vanilla JavaScript. Users can create multiple pets with independent stat systems that update in real time.

Live Demo → View on GitHub →

The Concept

The goal was to build a small interactive browser game that simulates a virtual pet lifecycle. Each pet maintains its own hunger, energy, and happiness states that evolve independently over time.

The Technical Approach

The application was built using semantic HTML, modular CSS, and vanilla JavaScript. Dynamic DOM rendering is used to generate pet cards, while timer functions control stat updates.

Key Features

  • Create up to four independent pets
  • Real-time stat decrease using timer logic
  • Dynamic card rendering per pet
  • Fetch API integration for animal images
  • Hybrid API + local fallback image handling
  • Restart game functionality

Technical Challenges

A key challenge was handling public API limitations and CORS restrictions. Some endpoints blocked direct browser requests. A hybrid solution was implemented, combining public APIs with local fallback images to ensure stable rendering.

Reflection & Next Improvements

This project strengthened my understanding of asynchronous JavaScript, state management for multiple dynamic components, and structured UI rendering.

Future improvements could include persistent state storage, enhanced UI feedback based on mood states, and extended gameplay mechanics.
